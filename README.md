                                       practical 2
Summary:
        Linear Search and Binary Search are two common searching techniques used to find an element in a list or array.
        Linear Search checks each element one by one from the beginning until the required element is found or the list ends. It does not require the data to be sorted. Its           time complexity is O(n).
        Binary Search repeatedly divides the search range into two halves and compares the middle element with the target. It requires the array to be sorted. Its time                complexity is O(log n).
        Binary Search is much faster than Linear Search for large, sorted datasets.
coclusion:
          Linear Search is simple and useful for small or unsorted datasets, but it can take more time when the number of elements is large. Binary Search is more efficient             for large, sorted datasets because it eliminates half of the remaining elements after each comparison.
          Therefore, Linear Search is easier to implement, while Binary Search provides better performance when the data is sorted. Both algorithms are important fundamental            searching techniques in data structures and algorithms.

summary:
        Max Heap Sort is a sorting algorithm that uses a Max Heap data structure. It first builds a Max Heap, where the largest element is at the root, and then repeatedly          moves the largest element to the end of the array. The process continues until the array is sorted in ascending order.

conclusion:
           Max Heap Sort is an efficient sorting algorithm with a time complexity of O(n log n). It does not require extra array space, making it useful when memory                    efficiency is important.
